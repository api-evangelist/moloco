## API Reference
- [DecideAdProducts](https://mcm-docs.moloco.com/reference/rmpdecisionapi_decideadproducts.md): Request product ads by auction. Server host may vary by platform. Moloco's staff will provide accurate host information.
- [DecideAdBrands](https://mcm-docs.moloco.com/reference/rmpdecisionapi_decideadbrands.md): Request brand ads by auction. Server host may vary by platform. Moloco's staff will provide accurate host information.
- [DecideAdDisplay](https://mcm-docs.moloco.com/reference/rmpdecisionapi_decideaddisplay.md): Request display ads by auction. Server host may vary by platform. Moloco's staff will provide accurate host information.
- [DecideAdReservedDisplay](https://mcm-docs.moloco.com/reference/rmpdecisionapi_decideadreserveddisplay.md): Request reserved display ads. Server host may vary by platform. Moloco's staff will provide accurate host information.
- [ListAdAccounts](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listadaccounts.md): List all the ad accounts on the platform.
- [CreateAdAccount](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createadaccount.md): Create a new ad account.
- [ReadAdAccount](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readadaccount.md): Read a ad account.
- [UpdateAdAccount](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updateadaccount.md): Update an ad account.
- [UpdateAdAccountStateInfo](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updateadaccountstateinfo.md): Update an ad account's state info.
- [QueryAudienceSummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryaudiencesummary.md): Read summarized reporting information of campaign with respect to audience targeting.
- [QueryPlacementSummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryplacementsummary.md): Read summarized reporting information of campaign with respect to placement targeting.
- [QueryAdAccountSummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryadaccountsummary.md): Read summarized reporting information of an ad account.
- [QueryAdManagerAccountSummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryadmanageraccountsummary.md): Read summarized reporting information of an ad manager account.
- [QueryPlatformSummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryplatformsummary.md): Read summarized reporting information of a platform.
- [QueryKeywordSummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querykeywordsummary.md): Read summarized reporting information of campaigned keywords.
- [ReadCampaignForecast](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readcampaignforecast.md): Show campaign forecast metrics such as click, imp, and purchase when an advertiser sets up their campaign.
- [ReadCampaignGuidance](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readcampaignguidance.md): Read guidance for a reasonable campaign setup.
- [QuerySuggestedItems](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querysuggesteditems.md): Query suggested catalog items associated with the ad account. Prior to using this API, please get in touch with the RMP associate to ensure correct configuration of this feature.
- [ReadItemBasedCampaignGuidance](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readitembasedcampaignguidance.md): Get item-based guidance recommendations for campaign optimization based on item performance analysis.
- [ListCampaignReviews](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listcampaignreviews.md): List campaign reviews.
- [CreateCampaignReview](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createcampaignreview.md): Create a campaign component's review. It generates the review for the given campaign's resources such as assets or landing page
- [UpdateCampaignReviewsBulk](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updatecampaignreviewsbulk.md): Update campaign components' reviews in bulk.
- [UpdateCampaignReview](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updatecampaignreview.md): Update a campaign component's review. It updates the review status of the given campaign's resources such as assets or landing page
- [ListCampaigns](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listcampaigns.md): List all the campaigns of an ad account.
- [CreateCampaign](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createcampaign.md): Create a campaign of an ad account. The daily_budget field is deprecated. Please use the budget field as an alternative.
- [ReadCampaign](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readcampaign.md): Read a campaign of an ad account.
- [UpdateCampaign](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updatecampaign.md): Update a campaign of an ad account.
- [QueryItemsCampaign](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryitemscampaign.md): Query catalog items associated with the campaign
- [QueryCampaignItemsHistory](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querycampaignchangelogitems.md): Query items' history in the campaign.
- [QueryCampaignHistory](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querycampaignchangelogs.md): Query campaign history.
- [QueryWalletHistory](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querywalletaccounthistory.md): Query wallet account history.
- [QueryAdManagerAccountHistory](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryadmanageraccountchangelogs.md): Query the ad manager account history.
- [QueryCreditsHistory](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querycredithistory.md): Query credits history. To be used for spending limit credit.
- [ListSpendingLimits](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listspendinglimits.md): List all spending limits of an ad account. Currently, an ad account can have a single spending limit.
- [ReadSpendingLimit](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readspendinglimit.md): Read spending limit of the ad account.
- [UpdateSpendingLimit](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updatespendinglimit.md): Update a spending limit.
- [QuerySpendingLimits](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryspendinglimits.md): Query all spending limits for the platform.
- [ListCredits](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listcredits.md): List credits of the ad account that has spending limit.
- [TopUpCredits](https://mcm-docs.moloco.com/reference/rmpmanagementapi_topupcredit.md): Top up an amount of money (VAT exclusive) to the credits balance.
- [WithdrawCredits](https://mcm-docs.moloco.com/reference/rmpmanagementapi_withdrawcredit.md): Withdraw an amount of money (VAT exclusive) from the credits balance of the ad account.
- [QueryCredits](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querycredits.md): Query all credits for the platform using spending limit.
- [QuerySpendingLimitCreditHistory](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryspendinglimitcredithistory.md): Query spending limit credits history.
- [QueryCustomTargetKeys](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querycustomtargetkeys.md): Query all available custom target keys for the platform.
- [QueryCustomTargetValues](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querycustomtargetvalues.md): Query all available custom target values for a given key.
- [ReadCustomTargetKeysBulk](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readcustomtargetkeysbulk.md): Read custom target keys in bulk.
- [ReadCustomTargetValuesBulk](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readcustomtargetvaluesbulk.md): Read custom target values in bulk.
- [QueryCustomTargetDailySummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querycustomtargetdailysummary2.md): Retrieve the custom targeting daily summary reports for a single line item.
- [QueryCustomTargetDailySummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querycustomtargetdailysummary.md): Retrieve the custom targeting daily summary reports for a single line item.
- [ReadCustomTargetKeysWithCustomReportBulk](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readcustomtargetkeyswithcustomreportbulk.md): Read the keys that have available report data in bulk.
- [ListImageAssets](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listimageassets.md): List all the image assets.
- [CreateImageAsset](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createimageasset.md): Create image asset
- [ReadImageAsset](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readimageasset.md): Read image asset information
- [ListVideoAssets](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listvideoassets.md): List all the video assets.
- [CreateVideoAsset](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createvideoasset.md): Create video asset
- [ReadVideoAsset](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readvideoasset.md): Read video asset information
- [CreateBulkImageUploadSession](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createbulkimageuploadsession.md): Create session for bulk image upload
- [CreateBulkVideoUploadSession](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createbulkvideouploadsession.md): Create session for bulk video upload
- [UpsertOrderWithLineItems](https://mcm-docs.moloco.com/reference/rmpmanagementapi_upsertorderwithlineitems.md): Create or update an order along with its associated line items in a single atomic operation.
- [ReadOrder](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readorder.md): Read order information with line items.
- [QueryLineItemDailySummary](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querylineitemdailysummary.md): Retrieve the daily summary reports for a single line item.
- [ListReservedDisplayInventories](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listreserveddisplayinventories.md): List all eligible reserved display inventories.
- [QueryReservedInventoryForecast](https://mcm-docs.moloco.com/reference/rmpmanagementapi_queryreservedinventoryforecast.md): Query forecasted impressions for reserved inventory.
- [ListSpendCaps](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listspendcaps.md): List spend caps for an ad account.
- [CreateSpendCap](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createspendcap.md): Create a spend cap of an ad account.
- [ReadSpendCap](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readspendcap.md): Read a spend cap of an ad account.
- [UpdateSpendCap](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updatespendcap.md): Update a spend cap of an ad account.
- [ListWallets](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listwallets.md): List all wallets of an ad account. Currently, an ad account can have a single wallet.
- [TopUpWallet](https://mcm-docs.moloco.com/reference/rmpmanagementapi_topupwallet.md): Top up an amount of money (VAT exclusive) for the wallet of the ad account.
- [WithdrawWallet](https://mcm-docs.moloco.com/reference/rmpmanagementapi_withdrawwallet.md): Withdraw an amount of money (VAT exclusive) from a wallet of the ad account.
- [QueryWallets](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querywallets.md): Query all wallets for the platform.
- [QueryWalletTransactionHistory](https://mcm-docs.moloco.com/reference/rmpmanagementapi_querywallettransactionhistory.md): Query wallet transaction history.
- [ListAdManagerAccounts](https://mcm-docs.moloco.com/reference/rmpmanagementapi_listadmanageraccounts.md): List ad manager accounts
- [CreateAdManagerAccount](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createadmanageraccount.md): Create an ad manager account
- [ReadAdManagerAccount](https://mcm-docs.moloco.com/reference/rmpmanagementapi_readadmanageraccount.md): Read an ad manager account
- [UpdateAdManagerAccount](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updateadmanageraccount.md): Update an ad manager account
- [CreateUserDataDeletionRequest](https://mcm-docs.moloco.com/reference/rmpmanagementapi_createuserdatadeletionrequest.md): Requests for the User data deletion request. We process the request by deleting the user event data in the batch job.
- [RotateDataExportKey](https://mcm-docs.moloco.com/reference/rmpmanagementapi_rotatedataexportkey.md): Rotate the data export key. The previous keys associated with the platform's service account would be deleted.
- [UpdateItemStatusBulk](https://mcm-docs.moloco.com/reference/rmpmanagementapi_updateitemstatusbulk.md): Item Kill Switch API. Immediate removal of specified items from ad serving in bulk.
- [PostUserEvent](https://mcm-docs.moloco.com/reference/rmpeventapi_postuserevent.md): Post an individual user event. Server host may vary by platform. Moloco's account manager will provide accurate host information.
